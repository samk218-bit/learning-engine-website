# Learning Engine website

A responsive educational website and bilingual blog for Learning Engine, published on GitHub Pages at https://learningengine.in.

## Features

- Responsive homepage and category cards
- Blog index with search and filters for language/category
- Article layouts powered by Jekyll Markdown posts
- English and Hindi sample articles
- Social links to YouTube, Instagram and Facebook
- No WordPress required

## Publish a new article

Follow `PUBLISHING-GUIDE.md`. Create a Markdown file inside `_posts/` through GitHub's web interface and commit it. GitHub Pages builds the blog automatically.

## Local preview (optional)

GitHub Pages builds the site remotely. For a local Jekyll preview, install Ruby and Bundler, then use the GitHub Pages gem workflow documented by GitHub.
